# Paper Trading Desk

A display-only wallboard for Zack Spakowski’s **paper** crypto trading team.

**PAPER — simulated, no real money.** This page never places orders, holds no wallets, and stores no keys.

The desk polls `state.json` from this same site every few seconds. If the feed is missing or empty, it waits. It does not invent trades or balances.

Live page: https://zackspak.github.io/paper-trading-desk/

This is an evaluation dashboard, not a product for sale and not financial advice.
